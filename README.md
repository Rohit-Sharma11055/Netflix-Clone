# 🎬 Netflix Clone

An interacive **Netflix UI clone** that mimics the core front-end design and experience of the popular streaming platform. This project includes a **Sign Up page**, a dynamic **Home screen**, a **navigation bar**, and a scrollable list of **suggested movies and series**.

## 🚀 Features

- 📥 **Sign Up / Sign In Page UI**
  - Simple and Interactive form design
  - Styled similarly to Netflix’s real login page

- 🏠 **Home Screen**
  - Hero section with featured content
  - Scrollable sections for popular shows and movies

- 🧭 **Navigation Bar**
  - Netflix-styled nav with logo, menu items, and user avatar (static)

- 🎞️ **Movie & Series Suggestions**
  - Static or mock data used to render multiple rows of thumbnails
  - Responsive hover effects

## 🎨 Design

- Based on the original Netflix UI
- Custom color theme applied (slightly altered for uniqueness)

## 🛠️ Tech Stack

- **HTML**
- **CSS**
